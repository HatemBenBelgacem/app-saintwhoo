# Features

Eine Datei pro Anforderung. Die Übersicht steht in [../Anforderung.md](../Anforderung.md).

**Dateiname:** `ANF-<Nr>-<kurzer-name>.md` (z. B. `ANF-002-artikel-auflisten.md`)

**Aufbau einer Datei:**
1. Kopf-Tabelle (Priorität, Status, Rolle)
2. Beschreibung und User Story
3. Felder / Daten
4. Ablauf
5. Abnahmekriterien (AK-x, Gegeben / Wenn / Dann)
6. Annahmen
7. Nicht Teil der Anforderung

Neue Anforderung: Datei anlegen **und** eine Zeile in der Tabelle in `Anforderung.md` ergänzen.
